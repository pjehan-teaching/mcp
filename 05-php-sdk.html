Le SDK PHP

Le SDK PHP officiel

  • Paquet Composer mcp/sdk, développé par la PHP Foundation et le projet Symfony
  • SDK officiel de niveau 3, en version 0.8 : expérimental jusqu'à la version 1.0
  • Serveurs et clients, transports stdio et HTTP
  • Ères legacy et modern servies par le même code
  • Déclaration des tools, resources et prompts par attributs PHP

Dans la version 0.8, l'ère modern n'est servie qu'en HTTP : un serveur stdio parle l'ère legacy.

modelcontextprotocol/php-sdk

Installation

Le SDK nécessite PHP 8.1 ou plus. On ajoute symfony/finder pour découvrir automatiquement les classes annotées :

composer require mcp/sdk symfony/finder

Installation

Un premier serveur

<?php

require __DIR__ . '/vendor/autoload.php';

use Mcp\Capability\Attribute\McpTool;
use Mcp\Server;
use Mcp\Server\Transport\StdioTransport;

class Calculator
{
    /**
     * Additionne deux nombres.
     */
    #[McpTool]
    public function add(int $a, int $b): int
    {
        return $a + $b;
    }
}

exit(Server::builder()
    ->setServerInfo('Calculator', '1.0.0')
    ->setDiscovery(__DIR__, ['.'], excludeDirs: ['vendor'])
    ->build()
    ->run(new StdioTransport()));

Ce que fait le SDK

  • #[McpTool] transforme la méthode en tool ; son nom est celui de la méthode
  • Le docblock devient la description du tool
  • Les types des paramètres deviennent le inputSchema : int $a donne un entier obligatoire
  • Le SDK valide les arguments reçus avant d'appeler la méthode
  • setDiscovery() parcourt les dossiers à la recherche de classes annotées
  • StdioTransport lit stdin et écrit sur stdout

Jamais d'echo, de var_dump() ou de print_r() dans un serveur stdio : écrivez sur STDERR.

Le fil rouge : un gestionnaire de tickets

Tout au long du cours, vous allez exposer une application de tickets de support sous forme de serveur MCP.

  • Un ticket a un titre, une description, un statut (open ou closed) et un éventuel assigné
  • Données stockées dans SQLite
  • Code métier fourni : vous écrivez uniquement la partie MCP
tickets/
├── composer.json
├── schema.sql
├── server.php
└── src/
    └── TicketRepository.php

Objectif final : un modèle capable de lister, trier, assigner et fermer des tickets, avec un tableau de bord interactif.

{
    "autoload": {

}

Le schéma et quelques tickets d'exemple. Les instructions sont rejouables : le dépôt les exécute à chaque démarrage.

CREATE TABLE IF NOT EXISTS tickets (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    description TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'open',
    assignee TEXT
);

Code de départ : TicketRepository

Le dépôt renvoie de simples tableaux associatifs, que le SDK sait convertir en JSON.

<?php

namespace App;

use PDO;

class TicketRepository
{
    private PDO $pdo;

    public function __construct()
    {
        $this->pdo = new PDO('sqlite:' . __DIR__ . '/../tickets.sqlite');
        $this->pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
        $this->pdo->exec(file_get_contents(__DIR__ . '/../schema.sql'));
    }

    public function findAll(?string $status = null): array
    {
        $query = $this->pdo->prepare('SELECT * FROM tickets WHERE :status IS NULL OR status = :status');
        $query->execute(['status' => $status]);
        return $query->fetchAll();
    }

Code de départ : TicketRepository

    public function find(int $id): ?array
    {
        $query = $this->pdo->prepare('SELECT * FROM tickets WHERE id = ?');
        $query->execute([$id]);
        return $query->fetch() ?: null;
    }

    public function create(string $title, string $description): array
    {
        $this->pdo->prepare('INSERT INTO tickets (title, description) VALUES (?, ?)')
            ->execute([$title, $description]);
        return $this->find((int) $this->pdo->lastInsertId());
    }

    public function assign(int $id, string $assignee): void
    {
        $this->pdo->prepare('UPDATE tickets SET assignee = ? WHERE id = ?')->execute([$assignee, $id]);
    }

    public function close(int $id): void
    {
        $this->pdo->prepare("UPDATE tickets SET status = 'closed' WHERE id = ?")->execute([$id]);
    }
}
